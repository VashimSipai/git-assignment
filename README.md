# 🐍 Git Assignment

A **Python-based practical assignment** exploring Git version control workflows — including branching, merging, rebasing, and commit management.

---

## 📚 Topics Covered

- Initializing repositories
- Staging and committing changes
- Branching and merging strategies
- Rebasing and squashing commits
- Remote repositories and push/pull workflows
- Resolving merge conflicts

---

## ⚙️ Running

```bash
git clone https://github.com/VashimSipai/git-assignment.git
cd git-assignment
python3 main.py   # or whichever script applies
```
